# 项目概览

## 一句话定位

**书遥贝贝**是一款面向 0-3 岁家庭的**宝宝成长记录小程序**：喂养、睡眠、便便、生长、生病、里程碑、疫苗、体检随手记，
照片汇成成长时间轴；AI 直接长在这份家庭自己的记录上，负责「记得」和「归纳」，把判断权留给家长。

## 干什么用的（产品侧）

- **记录**：六类日常记录（喂养 / 睡眠 / 便便 / 生长 / 生病 / 里程碑）+ 疫苗、体检；今日小结带可展开的时间线。
- **共享**：一家人共用一个家庭空间，成员分「可写 / 只读」两种角色。
- **回顾**：照片时间轴、每日对照、成长曲线、月度/年度成长报告分享图。
- **工具**：按月龄匹配的辅食食谱库、疫苗计划、喂奶提醒等。
- **AI**：照护助手问答、一句话记一笔、每日小结、首页 AI 观察四个触点，详见 [AI 能力说明](/ai/README.md)。

## 技术侧的关键设计

1. **后端可整体切换**：业务代码只认 `src/services/api.js`，它按 `BACKEND` 常量把请求转发给
   `src/services/cloud/**` 或 `src/services/supabase/**`。两套实现保持「同形」，页面代码零改动、零感知。
2. **H5 强制回落 Supabase**：H5 端没有 `wx.cloud`，`src/services/api.js` 里用条件编译把后端钉死为 Supabase；
   H5 只作开发调试兜底，不作为对外产品。
3. **AI 只在微信小程序 + 云开发下可用**：它依赖 `wx.cloud.extend.AI`，其他环境会走兜底提示。
4. **AI 对话与每日小结只存本机**：对话历史、小结缓存都落在 `uni` 的本地 storage，不落库、不上传。
5. **照片私有**：云存储放照片，数据库里存的是相对路径，读取一律换签名链接。

## 全程有效的约束（接手前必读）

这些是项目推进过程中逐条确认过的硬约束，改代码时不要破坏：

- **不新增收费服务**：所有能力都要落在免费额度内（云开发个人版 + 小程序成长计划赠送的 AI 资源包）。
- **两套后端必须同时存在**：不允许删除或改写 Supabase 版实现，它必须随时可回滚。
- **登录只保留微信一键登录**（手机号/邮箱登录链路已在后续版本中下线，仅 Supabase 后端残留）。
- **破坏性操作先确认**：执行 SQL、建集合、部署云函数、清数据之前，先把内容展示给使用方确认。
- **只给家人用**：对外推广前需要先补数据脱敏（AI 会把记录原文，含家长备注，发给大模型）。
