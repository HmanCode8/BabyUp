## 四、阶段 3：域名与服务器 ICP 备案（与阶段 2 并行）

> 这是整条链上**唯一需要花钱**的环节，也是微信后台配置域名的前置条件。
>
> **当前状态**：✅ 域名已买　|　⬜ 服务器未购买（已确认）　|　⬜ ICP 备案未开始（依赖服务器）。

### 4.1 为什么必须做这一步

当前项目所有网络请求都指向 `https://ohdqqfbabkglkeysccpt.supabase.co`。该域名属于 Supabase，**不在你名下、无法以你的主体备案**，微信后台无法配置。

微信官方规定（[网络使用说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)）：

- 域名只支持 `https` / `wss`
- **域名必须经过 ICP 备案**
- 不支持 IP 地址或 localhost
- **不支持配置父域名，使用子域名**（即不能配 `example.com` 然后请求 `api.example.com`，必须精确配子域名）
- 不支持配置 `api.weixin.qq.com`
- 新备案域名需 **24 小时后**才可配置

解决方案：**用你自己的已备案域名反向代理到 Supabase**。

```
小程序 → https://api.你的域名.com → 你的国内服务器(Nginx) → https://ohdqqfbabkglkeysccpt.supabase.co
```

## 五、阶段 4：服务器反向代理配置

### 5.1 安装 Nginx 与证书

```bash
# 以 Ubuntu 为例
sudo apt update && sudo apt install -y nginx

# 用 Certbot 申请证书（会把证书放到 /etc/letsencrypt/live/你的域名/）
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d api.你的域名.com
```

### 5.2 写入反向代理配置

新建 `/etc/nginx/conf.d/supabase-proxy.conf`：

```nginx
server {
    listen 443 ssl;
    http2 on;
    server_name api.你的域名.com;

    ssl_certificate     /etc/letsencrypt/live/api.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.你的域名.com/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;

    # 照片上传，Supabase 单文件上限 50MB
    client_max_body_size 50m;

    location / {
        proxy_pass https://ohdqqfbabkglkeysccpt.supabase.co;

        # ★ 最关键：Supabase 靠 Host 识别项目，必须重写回原域名
        proxy_set_header Host ohdqqfbabkglkeysccpt.supabase.co;
        # ★ 同样关键：TLS SNI 也必须是原域名，否则握手失败
        proxy_ssl_server_name on;
        proxy_ssl_name ohdqqfbabkglkeysccpt.supabase.co;

        proxy_http_version 1.1;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 清掉来源标记，避免 Supabase 侧做来源判断
        proxy_set_header Origin "";
        proxy_set_header Referer "";

        proxy_connect_timeout 15s;
        proxy_read_timeout    60s;
        proxy_send_timeout    60s;
    }
}
```

**两个绝对不要做的事**：

1. **不要清掉 `Authorization` 请求头** —— Supabase 全靠它鉴权。Nginx 默认透传，不要手动改写。
2. **不要开 CDN 缓存** —— 照片签名 URL 带过期 token，缓存后必然 403。

### 5.3 生效并验证

```bash
sudo nginx -t          # 检查语法
sudo systemctl reload nginx
```

> 官方文档：[域名管理](https://developers.weixin.qq.com/doc/oplatform/developers/basic_func/domain.html)　|　[网络使用说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)

### 6.1 配置路径

### 6.2 三个列表都要填同一个域名

- [ ] **request 合法域名** → `https://api.你的域名.com`
- [ ] **uploadFile 合法域名** → `https://api.你的域名.com`
- [ ] **downloadFile 合法域名** → `https://api.你的域名.com`

缺一个，对应功能必然失效：只填 request 会导致照片上传/显示全挂。

`业务域名` 仅 `web-view` 需要，本项目没用 `web-view`，且**个人主体不支持配置业务域名**，不用填。

### 6.3 填写规则（踩错就是白填）

| 规则 | 说明 |
|---|---|
| 必须 HTTPS | 不支持 http |
| **不能带路径** | `https://api.你的域名.com` ✅　`https://api.你的域名.com/api` ❌ |
| **端口要么不写、要么写全** | 不写端口则请求 URL 里也不能出现端口，**连默认的 443 都不能写**（写 `:443` 会失败） |
| 不能是 IP 或 localhost | 域名必须经过 ICP 备案 |
| **不支持父域名覆盖子域名** | 必须精确填 `api.你的域名.com`，填根域名无效 |
| 新备案域名需等 24 小时 | 刚备案完立刻配会失败，等一天 |
| **修改次数受限** | 每个自然月内修改超过 5 次，需等下月重置。**不要反复试错** |
| 生效时间 | 保存后一般 5~30 分钟生效 |

若后台要求上传域名所有权校验文件（形如 `MP_verify_xxxxxx.txt`），把文件放到站点根目录并确保可通过 `https://api.你的域名.com/MP_verify_xxxxxx.txt` 访问。

| 4 | **隐私指引勾错** | 勾成"未采集隐私"会触发 `appid privacy api banned` | 见 7.4 |
| 5 | **域名修改超限** | 每自然月最多改 5 次 | 先在 curl 验证通过，再一次性配到后台 |
| 6 | **短信核验超时** | 工信部短信 24 小时内未核验，备案作废 | 备案期间保持手机畅通，及时核验 |
| 7 | **备案后改名** | 改名会导致备案失效 | 上线前别改名 |
| 8 | **服务器单点** | 服务器挂了小程序全挂 | 配监控告警 |
| 9 | **延迟** | 服务器在大陆、Supabase 在境外，每次请求多一跳跨境 | 可接受；彻底解决需整体迁到国内云 |
| 10 | **出站流量成本** | 照片经你服务器中转，出站流量算你的 | 留意流量包额度 |

## 附：现在最该做的两件事

> 你已完成：个人主体确认、认证（审核中）、小程序备案（已提交、审核中）、域名购买。
> 未完成：**服务器**、ICP 备案、反代配置、隐私指引、真机验证、提审。

1. **盯紧工信部短信** —— 见 [3.3](#33-等待审核三个环节)。
   小程序备案三个环节里**唯一的限时动作**：短信到手后 **24 小时内**必须到工信部系统核验，超时申请作废、重新排队。这几天手机保持畅通、别把短信当垃圾短信删了。

2. **买国内服务器** —— 见 [4.2.2](#422-购买国内轻量应用服务器)。
   这是目前整条链**唯一的硬卡点**：没服务器 → 提交不了 ICP 备案 → 微信后台配不了域名 → 小程序发不出去。
   买法：与你域名**同一家云厂商**的轻量应用服务器，最低配、**包年包月且剩余 ≥3 个月**、**必须在中国大陆境内**。

**顺手能做完的**：阶段 6 隐私保护指引，5 分钟能配完。

**买服务器前先确认一件事**：域名实名认证是否已通过（见 [4.2.1](#421-注册域名)）。它是 ICP 备案的前置条件，没过就得等。
